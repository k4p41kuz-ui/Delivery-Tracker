# Delivery Mileage Tracker

Mobile-first delivery mileage tracker.

## Current version
- Start/finish trips using odometer readings
- Add deliveries and optional delivery distance
- Daily and weekly totals
- Local browser storage
- iPhone-friendly layout
- PWA manifest included

## Free hosting
This project is a static web app and can be hosted on Render as a Static Site. No Mac is required.

## Next upgrade
For multi-device/cloud storage, connect Supabase and replace localStorage with a database.
