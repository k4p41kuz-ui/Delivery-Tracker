# Driver UI notes

- Large Start Drive button.
- High-contrast live distance.
- Delivery count always visible.
- Add Delivery should be one tap.
- Never require text entry while moving.
- Show current delivery address after GPS reverse-geocoding.
- Show route on a map after the drive.
- Finish Drive should require confirmation to prevent accidental taps.
- History should support day/week/month filtering.
- Export should share CSV through the iOS share sheet.
